# Animated Terminal Name

A colorful, animated terminal application built with Node.js. It displays your name in large ASCII art with cycling neon gradients.

## Features

- Animated neon gradient colors
- Large ASCII text using Figlet
- Multiple color themes
- Continuously refreshing terminal display
- Simple Node.js setup

## Tech Stack

- Node.js
- Figlet
- gradient-string
- Chalk

## Prerequisites

- Node.js
- npm
